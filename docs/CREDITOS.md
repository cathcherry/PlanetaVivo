# Créditos e origem dos recursos

## Terra — `assets/terra.jpg`

Imagem **Blue Marble Next Generation** (BMNG) da NASA, distribuída no pacote `basemap-data` da biblioteca Basemap para Python como `bmng.jpg`. O arquivo usado no jogo foi redimensionado para 2048 × 1024 para reduzir consumo de memória no Android.

Créditos recomendados: **NASA Earth Observatory / NASA Goddard Space Flight Center; Blue Marble Next Generation, Reto Stöckli e colaboradores**.

Informações: https://earthobservatory.nasa.gov/features/BlueMarble e https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/

Consulte as diretrizes de uso de mídia da NASA caso publique ou comercialize o jogo. Não sugerir patrocínio/endosso da NASA.

## Nuvens — `assets/nuvens.png`

Textura transparente procedural criada especialmente para este protótipo. **Não representa observações meteorológicas reais**.

## Céu — `assets/estrelas.jpg`

Panorama estrelado procedural criado para o protótipo. **Não representa um mapa astronômico real**.

## Código e estrutura

Scripts, shaders, configuração e cena preparados para este projeto. Para o ícone inicial, o editor utiliza o ícone padrão do Godot até definirmos uma identidade visual própria.
